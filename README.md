# Validação de Formulário

Projeto desenvolvido para praticar validação de formulários utilizando JavaScript, criando uma experiência mais interativa e segura para o preenchimento dos dados pelo usuário.
A aplicação verifica os campos obrigatórios antes do envio, identifica informações não preenchidas e apresenta mensagens de orientação ao usuário. Após o preenchimento correto, os campos recebem uma indicação visual de validação e o formulário pode ser enviado.

🚀 Funcionalidades

Validação dos campos obrigatórios;<br>
Identificação de campos vazios;<br>
Exibição de mensagens de erro;<br>
Feedback visual para campos preenchidos corretamente;<br>
Remoção automática dos avisos conforme o usuário corrige os campos;<br>
Prevenção do envio do formulário quando existem campos inválidos;<br>
Limpeza do formulário após o envio bem-sucedido.

📚 Conceitos praticados

Durante o desenvolvimento, foram trabalhados conceitos importantes de JavaScript, como:

Manipulação do DOM;<br>
Eventos de formulário;<br>
addEventListener;<br>
preventDefault();<br>
querySelector e querySelectorAll;<br>
Manipulação de classes com classList;<br>
Arrays e objetos;<br>
Validação e tratamento de dados do usuário.

🎯 Objetivo

O objetivo do projeto é aprimorar os conhecimentos em JavaScript e manipulação do DOM, desenvolvendo uma funcionalidade comum em aplicações web e proporcionando uma experiência de preenchimento mais clara e intuitiva para o usuário.
